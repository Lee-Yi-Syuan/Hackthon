# 資安無慮

**把資安宣導拆開，塞進補助流程的每一關。**

115 年梅竹黑客松參賽作品 — 競賽主題：《AI 領航青年數位工具補助・解決資安無慮》（新竹市政府青年發展中心）

---

## 這是什麼

新竹市是全國第一個補助青年購買 AI 工具的城市。問題在於：補助款買來的工具若造成使用者自身、其雇主或客戶的資料外洩，這筆補助就成了傷害。

傳統做法是在申請頁掛一份「使用須知」，然後所有人直接捲到底按同意。

這個原型把宣導拆成五段，分別放進**申請、綁定、等待、核銷、撥款**。申請人的動線沒有變長，但每一關都會帶走一件事——因為那件事出現在他**真的會遇到它的那一刻**。

## 線上展示

單一 HTML 檔，無需建置。直接用瀏覽器開啟 `app.html` 即可。

> 若以沙箱化的環境（如線上分享連結）開啟，內容安全政策會封鎖所有對外請求，匯率介接會自動退回內建備援值。這是預期行為。本機開啟則可實際連通。

## 五個階段

| 階段 | 資安節點 | 對應解題方向 |
|---|---|---|
| ① 申請 | 親切的「AI 小幫手」逐欄覆誦你的資料，從身分證字號推出戶籍地與性別，送出瞬間畫面轉黑，演出資料被打包送往 `unknown-host` | 一 |
| ② 綁定 | LINE 搜尋「新竹青年」跑出三個帳號，兩個是冒用的。選完再看授權範圍：官方只要 2 項權限 | 三 |
| ③ 審核 | 把 5–7 個工作天的等待期變成教室：5 則各 30 秒的微課程，每則附一起真實事件 | 二、四 |
| ④ 核銷 | 12 項資安檢核清單。**要佐證，不要打勾**：答出設定路徑、填入查到的數值、附上設定截圖 | 六 |
| ⑤ 撥款 | 進度追蹤 ＋ 銅／銀／金三級素養徽章，徽章換得到實質好處而非榮譽 | 二、五 |

另含可列印 A4 一頁的「AI 安全使用懶人包」圖卡（解題方向四）與 API 介接說明頁。

## 設計上的四個取捨

1. **宣導不另開一頁，拆進既有動線** — 另開的「資安須知」頁面沒有人看
2. **先示範風險，再講規則** — 先讓人被自己的身分證字號嚇一次，後面的規則才聽得進去
3. **檢核清單要佐證，且答錯不退件** — 門檻 12/12 但可無限重答，每次附上正確做法。退件率高的政策第二年沒人申請
4. **素養認證要有實質誘因** — 次年免重填、優先審查、種子講師鐘點費

## 自動審核

表單共 17 條審核規則，分三類：

- **本機即時（13 條）** — 填寫過程中即判定，送出前擋下不符項目
- **API 介接（3 條）** — 送出後由系統呼叫外部服務
- **人工審查（1 條）** — 僅「工具用途與計畫是否相稱」需要人

其中一條是真正的勾稽：**身分證字號首碼 vs 戶籍地址縣市**。填 `O` 開頭卻選桃園市，當場標紅。

## API 介接現況

| 介接 | 狀態 | 說明 |
|---|---|---|
| 即時市場匯率 | ✅ 可直連 | `open.er-api.com` — 免金鑰、回應 CORS |
| 全國行政區清單 | ✅ 免介接 | 22 縣市 368 筆已內建，零延遲、離線可用 |
| 財政部電子發票查驗 | ⛔ 需後端 | `appID` 屬機密，放前端等於公開 |
| 內政部戶政資料介接 | ⛔ 需後端 | 限機關以 T-Road 申請，不對外開放 |
| 衛福部社會救助資料 | ⛔ 需後端 | 限機關介接 |
| LINE Login v2.1 | ⛔ 需後端 | `channel_secret` 屬機密 |

後四組不是「還沒接」，是**前端本質上不該接**。上線需由市府端實作四條代理路徑：
`/api/bot-rates`、`/api/einvoice/verify`、`/api/household/verify`、`/api/social/low-income`

⚙ API 頁內建「實際試連」按鈕，會真的發出請求並回報當前環境下的實際結果。

## 技術

- 單一 HTML 檔，無建置流程、無相依套件
- Hash 路由（`#/apply`、`#/checklist`…），瀏覽器上一頁可用
- 狀態存於 `localStorage`，失敗時自動降級為記憶體
- 完整深色模式（所有顏色走 CSS 權杖，無任何顏色只存在於 media query 內）
- 手機優先；懶人包與檢核聲明書有獨立列印樣式（A4 一頁）
- 字型：Noto Serif TC ／ Noto Sans TC ／ JetBrains Mono

## 已知限制

- **補助期間的結束日 `2026-12-31` 為推定值**。題目僅載明「115 年 4 月起」，未給截止日。自動審核的「購買日期在補助期間內」以此判定，正式數字需確認後修改（見 `PERIOD` 常數）
- **四起資安事件與各工具設定路徑未經查證**，係依公開報導記憶撰寫。各服務介面會隨版本調整，正式使用前請自行核對
- **解題方向五（工作坊）僅有內容，未實作互動**
- 承辦端後台為硬編示意資料，尚未接上實際的自動審核結果
- 附件上傳、匯率換算等互動尚未完整實測

## 隱私

本原型**不連線、不上傳任何個人資料**。所有判斷於瀏覽器本機完成；附件僅讀取檔名、副檔名與大小做格式檢查，檔案內容不會離開裝置。唯一的對外請求是匯率查詢，不夾帶任何使用者資料。
